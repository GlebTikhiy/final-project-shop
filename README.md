# 🛍️ Final Project Shop

**Final Project Shop** — это одностраничное веб-приложение (SPA), имитирующее полноценный интернет-магазин с клиентской частью и административной панелью. Проект создан для демонстрации навыков фронтенд-разработки с использованием современных технологий.

## 🚀 Технологии

- **React** — библиотека для создания пользовательского интерфейса.
- **Vite** — инструмент сборки для быстрого старта и разработки.
- **Redux Toolkit** — удобное управление состоянием (товары, корзина, авторизация).
- **React Router** — маршрутизация и навигация по страницам.
- **React Hook Form** — простая работа с формами и валидацией.
- **Axios** — отправка HTTP-запросов к API.
- **json-server** — локальный mock-сервер для REST API.
- **concurrently** — запуск фронтенда и API одновременно.
- **CSS** — стилизация компонентов.

## 📦 Возможности

### Клиентская часть
- Просмотр каталога товаров.
- Подробная страница каждого товара.
- Добавление товара в корзину.
- Управление количеством и удаление товаров в корзине.
- Итоговая стоимость и сохранение корзины в LocalStorage.
- Адаптивный интерфейс под все устройства.

### Административная панель
- Авторизация администратора (валидация email и пароля).
- Добавление, редактирование и удаление товаров.
- Защита маршрутов — доступ к админке только авторизованным пользователям.

### Технические особенности
- Хранение авторизации и корзины в LocalStorage.
- Обработка загрузки и ошибок при запросах.
- Разделение проекта на компоненты, страницы и Redux-слайсы.
- Использование современного синтаксиса `.jsx`.

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd final-project-shop
```

2. Установите зависимости:
```bash
npm install
```

3. Запуск приложения и API одновременно:
```bash
npm run start
```
- Vite: http://localhost:3000
- json-server: http://localhost:3001

Альтернативно:
- Только клиент:
```bash
npm run dev
```
- Только API:
```bash
npm run server
```

## 🧭 Использование

### Пользователь:
- Главная страница — список товаров.
- Страница товара — описание и кнопка добавления в корзину.
- Корзина — изменение количества, удаление, общая стоимость.

### Администратор:
- Вход через `/admin/login`
- Управление товарами через панель `/admin`:
  - Добавление: форма нового товара.
  - Редактирование: изменить данные существующего.
  - Удаление: удалить товар.
- Выход через кнопку "Logout".

## 🛠️ Проблемы и решения

- **Конфликт портов**: изменить порт в `vite.config.js` или `package.json`.
- **CORS**: убедиться, что `json-server` запущен и доступен на `http://localhost:3001`.
- **Сброс корзины**: LocalStorage можно очистить вручную через инструменты разработчика.
